# Personal Budget Tracker

A web-based Personal Budget Tracker built with HTML, CSS, and JavaScript to help users manage their income, expenses, and savings goals.

## Features

- Add, edit, and delete income and expense transactions.
- Calculate total income, expenses, and remaining balance.
- Save transactions using browser local storage.
- Filter transactions by month.
- Search transactions by description and category.
- Filter transactions by income or expense type.
- View spending breakdowns by category using charts.
- Set savings goals and track progress.
- Calculate monthly savings needed to reach a financial target.
- Set a monthly spending budget with warning alerts.
- View a monthly financial dashboard.
- Export transactions to CSV.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser Local Storage

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Data Storage

The application uses browser local storage to save transactions and settings. Data is stored in the browser on the user's device and is not automatically synchronised between devices.

This project was developed as a practical learning exercise to build skills in web development, JavaScript programming, data handling, and user interface design.
